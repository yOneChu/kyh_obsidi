## AI활용사례 제목

주제: PLM 실시간 연계형 AI 에이전트 구축 — 데이터 조회부터 인사이트 도출까지 자동화
-PLM 데이터분석, 2시간에서 5분으로 — AI 에이전트 기반 업무 자동화
- PLM AI 에이전트 기반 업무 자동화 - 데이터 분석, 2시간에서 5분으로
- PLM 데이터분석, 2시간에서 5분으로 — AI 에이전트 기반 실시간 연계 자동화



## 1. AI를 활용하게 된 배경 또는 기존 업무의 불편사항

기존 PLM 데이터분석 업무는 여러 단계를 수작업으로 순차 진행해야 했습니다. 
PLM에 접속해 전산화요청·비표준처리·ECO 등 PLM에 있는 데이터를 기간별로 조회하고 대량의 데이터를 엑셀로 추출하는 데만 약 20분, 이후 피벗·VLOOKUP 등 엑셀 수식으로 데이터를 정제하는 데 약 20~40분이 소요됐습니다. 여기에 리드타임 등 항목별 분석에 1시간 이상이 들었고, 최종 인사이트 도출은 시간 제한 없이 사람의 역량에 의존했습니다.

이 과정은 반복 작업이 많아 시간 소모가 크고, 수식 처리 과정에서 오류가 발생할 수 있으며, 무엇보다 사람이 놓치는 인사이트가 생길 수 있다는 한계가 있었습니다. 총 2시간 이상 걸리던 이 흐름을 단축할 방법을 고민하다 AI 에이전트(Antigravity) 활용을 고안하게 되었습니다.


## 2. 구체적인 활용 방법

**1) 활용 업무**  
PLM 데이터분석 및 보고서 작성 업무에 활용했습니다. 구체적으로는 전산화요청·비표준처리 등 항목을 기간별로 조회·추출하고, 정제·분석하여 리드타임 등 인사이트를 도출하는 작업입니다. 기존에 PLM 조회 → 엑셀 정제(피벗·VLOOKUP) → 분석 → 인사이트 도출로 이어지던 수작업 과정을 AI 에이전트가 일괄 처리하도록 구성했습니다.

**2) 사전 준비 (환경 구축 -완료)**  
AI가 PLM 데이터를 직접 다룰 수 있도록, PLM과 AI 사이에 중간 서버를 구축했습니다.
- 데이터 조회·연동용 **API**를 정의
- AI가 데이터를 정확히 이해하도록 **데이터 명세서(DB 스키마·필드·의미 정의)**를 작성 — 결과 품질을 좌우하는 가장 중요한 준비 단계

**3) 작성(실행) 순서**
1. 사용자가 필요한 분석 내용을 **자연어 프롬프트**로 요청
2. Antigravity가 요청을 해석하여 필요한 데이터 항목·조건을 판단
3. 중간 서버와 통신하여 PLM의 **DB 스키마·API를 분석**
4. 조건에 맞는 데이터를 **추출 → 전처리 → 정제**
5. 리드타임 등 기준으로 **분석 수행 및 인사이트 도출**
6. 결과를 검토·확인 후 보고서에 반영

**4) 프롬프트 예시**
> "OO기간의 전산화요청 데이터를 조회해서 항목별 리드타임을 분석하고, 지연이 많은 항목 위주로 인사이트를 정리해줘."

> "비표준처리 건을 기간별로 집계하고, 처리 지연 상위 항목과 원인 후보를 요약해줘."

(사용자는 조회 조건·분석 관점만 자연어로 전달하며, 데이터 위치나 수식 작성은 지정하지 않습니다.)


**5) 결과 검증 (원본 데이터 자동 추출)**  
분석 결과와 함께, 사용된 **원본 데이터를 CSV·Excel 파일로 자동 추출**되도록 구성했습니다. 이를 통해 보고서에 담긴 수치와 인사이트가 실제 데이터에 근거한 것인지 직접 대조·확인할 수 있습니다. AI가 도출한 분석 결과를 사람이 원본과 비교 검증할 수 있어, 결과의 신뢰성과 투명성을 확보할 수 있습니다.

**6) 사용 기능 요약**
- **AI 에이전트(Antigravity)** — 자연어 요청 해석 및 데이터 추출·전처리·분석·인사이트 도출 자동 수행
- **중간 서버(API·데이터 명세서)** — PLM과 실시간 연계, AI가 DB 스키마·API를 분석할 수 있는 기반 제공
- **자연어 인터페이스** — 엑셀 수식·SQL 없이 요청 가능
- **원본 데이터 자동 추출(CSV·Excel)** — 분석 결과를 원본과 대조하여 검증 가능


3) 처리 흐름
자연어 요청 → Antigravity → 중간 서버(API·데이터 명세서) → PLM DB 스키마·API 분석 → 데이터 추출·전처리·분석 →  검증 데이터 자동 추출 → 인사이트 도출 


## 3. 활용 결과 및 기대 효과

PLM과 실시간 연계되는 중간 서버를 구축하고, 조회·연동용 API와 데이터 명세서(스키마·필드 정의)를 정의했습니다. Antigravity가 필요한 데이터가 발생하면 중간 서버와 통신하여 PLM의 DB 스키마·API를 분석하고, 데이터 추출부터 전처리·분석·인사이트 도출까지 일괄 수행하도록 만들었습니다.

- **시간 단축**: 총 2시간 이상 걸리던 업무를 5분 이내로 단축했습니다.
- **반복 작업 자동화**: 조회·정제·리드타임 계산 등 정형 반복 작업을 자동화해 수작업 오류 가능성을 줄였습니다.
- **분석 품질 향상**: 사람이 놓칠 수 있는 관점을 AI가 함께 도출해 분석의 폭과 일관성을 높였습니다.
- **확장 기대효과**: 중간 서버·데이터 명세서 기반 구조라 다른 분석 항목이나 팀원 요청으로 재사용·확대할 수 있으며, 팀 전체 확산 시 부서 단위 생산성 향상을 기대할 수 있습니다.


## 4. 장점

- 2시간 이상의 업무가 5분 이내로 줄어드는 체감 효과가 매우 큽니다.
- 중간 서버를 통한 PLM 실시간 연계로, 매번 수동 추출 없이 최신 데이터를 바로 분석에 활용할 수 있습니다.
- 자연어로 요청할 수 있어 복잡한 엑셀 수식이나 SQL을 몰라도 팀원이 활용할 수 있는 접근성을 갖췄습니다.
- 정형화된 반복 업무에서 벗어나, 절감된 시간을 실제 의사결정과 개선 활동에 투입할 수 있습니다.



## 5. 한계점 및 주의사항

- **초기 구축 부담**: 중간 서버 설계와 API·데이터 명세서 정의에 상당한 초기 작업이 필요합니다. 특히 데이터 명세서를 정확히 정의하는 것이 결과 품질을 좌우하는 가장 중요한 부분입니다.
- **유지보수 필요**: PLM의 DB 스키마나 API가 변경되면 명세서와 연동부를 함께 갱신해야 하므로 지속적인 관리가 필요합니다.
- **결과 검증 필수**: AI가 도출한 분석·인사이트는 오류나 잘못된 해석 가능성이 있어, 최종 판단은 사람이 검증하는 절차가 반드시 필요합니다.
