전체 흐름 (runOneCycle)
프로젝트호기번호 → 영업사양 ouid 조회 → 로그인 → WIP 생성 → 종속사양 산출 → BOM 계산

- 종속사양 산출 응답을 받지 못하면 BOM 계산은 하지 않고 거기서 멈춥니다.
- 결과 객체에 bomMessage를 추가했습니다. 이제 success는 BOM 계산까지 응답을 받았을 때만 true입니다.

BOM 계산은 참고 코드와 같은 방식입니다.
- ouid를 elv_info$vf@가 붙은 소문자 형태로 바꿔서 보냅니다. 그래서 ac45dd18만 넘겨도 되고 전체 ouid를 넘겨도 됩니다.
- 응답을 못 받으면 3초 간격으로 최대 3회까지 다시 시도합니다.
- 테스트 코드처럼 전역 쿠키를 쓰지 않고, 기존 함수들처럼 PlmSession을 넘겨받아 씁니다.

확인이 필요한 부분
- 응답을 기다리는 시간은 기존 설정 그대로 120초입니다. BOM 계산이 이보다 오래 걸리면 응답을 못 받은 것으로 처리돼 다시 시도합니다.
- 서버에서 첫 번째 계산이 계속 돌고 있다면 같은 계산이 중복으로 시작될 수 있습니다.
- 실제로 오래 걸린다면 BOM 계산만 대기 시간을 늘리는 게 좋습니다.
