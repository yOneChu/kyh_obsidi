```
BOM 이상감지라는 주제로 발표 준비를 하려고해. 배경은 우리팀은 수배로직설계팀으로서 BOM을 제품의 영업사양을 바탕으로 자재를 수배하도록 하는 로직을 작성하는 팀이야. 그래서 우리가 매일 작성/수정 하는 로직을 바탕으로 수배되는 BOM들에 문제가 있는지 없는지 이상감지하는게 발표주제의 목적이야. 한번 발표자료에 사용할 배경에 대해 내용 서술해줘봐. 지금 브레이밍 스토밍 중이거든.
```

```
시스템으로 현재 개발한 부분은 아래와 같아. PLM시스템의 특정 호기를 선택해서 BOM을 만드는거야.  
그 호기들은 브랜드별로 2개정도 선택해. 브랜드 종류로는 NEX MR, NEX MRL, IXEL 등 있어.

- WIP생성 -> 동일정보 만들기 -> 속성값 변경 -> 종속사양 산출 -> BOM 계산

즉 많은 블럭별 로직을 작성해서 다음날 BOM계산을 돌리고 전날의 BOM과 비교해서 갑자기 수량이나 다른 자재로 수배된게 있는지 감지하는게 컨셉이야.
N
종합해서 발표를 위한 MD파일과 WORD로 1차 기획안 보고서 작성해줘봐
```


```
만약에 우리가 작성한 로직의 문맥적 오류를 발견하지 못한다면 잘못된 자재가 수배 or 수배가되지 않거나, 수량이 잘못나가는 문제가 발생하여 JQPR이 발생하여 실패 비용이 발생한다. 그러면 원인소명하고 업무적 스트레스도 받고 힘들어진다 는 내용도 넣어줘. 일단 WORD는 작성안해줘도되고 MD 파일로만 작성해줘
```
