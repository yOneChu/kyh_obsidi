### 1. 핵심 요약: `AA_FRAME`의 정체와 용도

`AA_FRAME`은 영업/설계 입력 특성코드가 아니라, **`EL_PB121A02` 초기 구간(`NO=6`)에서 하위 계산 로직 `CAL_AA_FRAME`(Version `7`)을 호출(`CALL`)하여 산출하는 '카 프레임 기준 가로 폭(Frame AA 치수)' 파생 변수**입니다.

* **핵심 목적**: 신설 현장에서는 카 외부가로 치수(`EL_ECAA`)와 카 프레임 기준 가로 치수가 동일하지만, **기존 카 가이드 레일을 재사용(`Y`)하거나 이설(`M`)하는 교체공사(`EL_DCARIL = ,Y,M`) 현장**에서는 기존 레일 간 거리(`EL_ECBG`, `CAR; BG`)에 맞춰 카 프레임 폭이 결정됩니다.
* 따라서 **신설 현장(`EL_ECAA` 기준)과 레일 재사용 교체공사 현장(`EL_ECBG - TH` 역산 기준)을 동일한 프레임 가로 규격(`AA`)으로 통합하여 안전난간대(`SAFETY GUARD`) 품번을 선정**하기 위해 사용됩니다.
* `CAL_AA_FRAME`의 `NO=2` 비고(`REMARKS`)에도 공통 용도가 아래와 같이 명시되어 있으며, 실제로 `B120A`, `B121A`, `EL_PB121A02`, `EL_PB121B`, `EL_PB125A` 등 카 프레임·탑빔·비상정지장치·안전난간대 계열 최신 PID 30개에서 공통 참조됩니다.
  > `"CAR FRAME, TOP BEAM, SAFETY, SAFETY GUARD 주석 / ISOLATION BRKT"`

### 2. `AA_FRAME` 산출 로직 상세 (`CAL_AA_FRAME`, Version `7`)

`EL_PB121A02`의 `INIT` 구간 `NO=6` (`KEY1=CALL`, `VAL1=CAL_AA_FRAME`)에서 실행되며, 전체 계산 규칙은 다음과 같습니다.

#### ① 벽 구조 / 브랜드 / 교체전 업체별 차감 보정치(`TH`) 결정 (`NO=5`~`8`)
상→하 순차 실행되므로 아래쪽 조건에 해당하면 `TH` 값이 갱신됩니다.

| 순번(`NO`) | 조건 (`SPEC` = `CON`)                                  | 조건 의미                                     | 산출값 (`KEY` = `VAL`) |
| :------: | :--------------------------------------------------- | :---------------------------------------- | :------------------ |
|   `5`    | `EL_BWALLT = T19_SD1`                                | WALL구조: T19 구조(벽두께 30mm)                  | `TH = 40`           |
|   `6`    | `EL_BWALLT = ,T19_EX1,T30_SD1`                       | WALL구조: T19L 확장(30mm) 또는 T30 구조(50mm)     | `TH = 58`           |
|   `7`    | `EL_ABRAND = ,NEX_MR,NEX_MRL` AND `EL_ASPSCD = KC01` | 브랜드 NEX_MR/MRL & 생산거점 `KC01`              | `TH = 50`           |
|   `8`    | `EL_ATYP = ,GTSS_E,GTSS` AND `EL_DSETUP = OT_GEN2`   | 기종 GTSS 계열 & 교체전 설치업체 오티스 Gen2(`OT_GEN2`) | `TH = 30`           |

#### ② 레일 재사용 여부에 따른 `AA_FRAME` 최종 산출 (`NO=10`~`11`)
* **`NO=10` (카 레일 재사용/이설 현장)**: `EL_DCARIL = ,Y,M` (`(재사용) CAR RAIL` = YES 또는 이설) 조건 만족 시 `GOTO = STOP`
  $$\text{AA\_FRAME} = \text{EL\_ECBG} - \text{TH}$$
* **`NO=11` (그 외 일반 신설 현장 등)**: 조건 없이 실행 후 `GOTO = STOP`
  $$\text{AA\_FRAME} = \text{EL\_ECAA} \quad (\text{CAR 외부가로 ; AA})$$

### 3. `EL_PB121A02` 내에서의 실제 활용 패턴

`EL_PB121A02` 전체 `3,611`행 중 앞쪽 구간(`NO=33`~`2895`)은 `EL_ECAA`(`CAR 외부가로 ; AA`, `2,261`건)나 `EL_ECCA`(`CAR 내부가로 ; CA`)를 직접 비교하는 반면, **후반부 `NO=2896` ~ `NO=3435` 구간(총 `486`행)에서 `AA_FRAME`을 조건(`SPEC`)으로 사용**합니다.

1. **적용 기종(`EL_ATYP`) 분포 (`486`행 기준)**
   * `GTSS`, `GTSS_E`: `430`건 (일반 `398`건 + 오티스 Gen2 교체공사 `OT_GEN2` 전용 `32`건)
   * `GTLX`, `GTLX_E`: `52`건
   * `WBSS_US` (북미수출용 MRL): `4`건

2. **산출 부품(`SAFETY GUARD`) 규격과의 매핑 검증**
   동일 조건에서 `AA_FRAME` 값만 다른 행의 산출 자재를 부품 API로 조회하면, 부품 마스터 `partSize`의 **`AA=` 규격 치수**와 정확히 1:1 대응합니다.
   * `NO=2896` (`WBSS_US`, `AA_FRAME=1787`, `EL_ECBB=1530`, `EL_ECEE=720`) → `12100542G0100` (`SIZE: CAPA=2100, AA=1787, BB=1530, EE=720`)
   * `NO=2897` (`WBSS_US`, `AA_FRAME=2092`, `EL_ECBB=1530`, `EL_ECEE=720`) → `12100542G0200` (`SIZE: CAPA=3000, AA=2092, BB=1530, EE=720`)
   * `NO=2909` (`GTSS`·`OT_GEN2`, `AA_FRAME=1400`, `EL_ECBB=1505`, `EL_ECEE=980`) → `12111066G0400` (`SPEC: GTSS,MOR,3B` / `SIZE: AA=1400,BB=1505,EE=980`)
   * `NO=2910` (`GTSS`·`OT_GEN2`, `AA_FRAME=1600`, `EL_ECBB=1505`, `EL_ECEE=980`) → `12111066G0500` (`SPEC: GTSS,MOR,3B` / `SIZE: AA=1600,BB=1505,EE=980`)

3. **문법상 참고 사항 (`CON` 공백 행)**
   * `AA_FRAME`이 포함된 `486`행 중 `374`행은 `1860`, `1660`, `1310`, `2060`, `1400` 등 고정 치수가 `CON`에 지정되어 있습니다.
   * 나머지 **`112`행(예: `NO=3083` → `12110717G9300`, `NO=3117` → `12110719G9100` 등)**은 `SPEC`에 `AA_FRAME`(및 `EL_ECBB`)만 입력되고 `CON`이 빈칸(`-`)입니다. 부품 마스터상 해당 품번들의 `partSize`는 `AA,BB=VAR`(비표준 가변 치수 품번)로 등록되어 있으나, 로직 문법 규칙상 `SPEC`만 존재하고 `CON`이 비어 있는 구간이므로 **`[확인 필요]`** 항목으로 함께 참고하시기 바랍니다.
